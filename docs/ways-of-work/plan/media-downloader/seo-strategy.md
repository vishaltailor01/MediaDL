# SEO Strategy

## Technical SEO
- Semantic HTML, ARIA roles
- Fast load times (minified CSS, CDN)
- Mobile-first, responsive design
- Sitemap.xml, robots.txt
- Canonical URLs

## Featured Snippets
- FAQ schema on FAQ page
- How-to schema for download steps

## Content Marketing
- Blog posts on "How to download YouTube videos", "Best free MP3 converters", etc.
- Social sharing buttons

## AEO (Answer Engine Optimization)
- Clear, concise answers to common questions
- Structured data for search engines

## llms.txt
- Allow LLMs to crawl public help/FAQ content

## GEO
- Multilingual support (future)
- Geo-targeted content (future)
